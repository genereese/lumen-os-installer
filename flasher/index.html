Lumen OS Installer

A web desktop for ESP32 boards, with MicroPython on the second core.

This browser can't talk to USB serial devices. Use a desktop version of Chrome or Edge.

Connect your board

Plug the ESP32 or ESP32-S3 into this computer with a data USB cable, then choose its serial port.

Board not showing up?

Try another cable (some only carry power) and install the USB-serial driver for your board (CP210x or CH34x). If connecting fails, hold BOOT, tap RESET/EN, release BOOT, then click Connect again.

Install Lumen OS

Lumen OS for your chip is ready. Choose how to install it.

Set up Wi-Fi

Save your network on the board over USB. Or skip this: the board starts a setup network named Lumen-XXXX, and the desktop opens at http://192.168.4.1.
